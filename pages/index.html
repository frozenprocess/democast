democast

Record scripted demo videos of a live website and a real terminal, side by side.

See the examples Read the reference

How it works

You write a YAML scene: title cards, captions, clicks and typing in the browser, commands in the terminal. democast plays it in headless Chrome, runs the commands for real, records the result and encodes MP4s for social media.

site: https://example.com/login
steps:
  - caption: Sign in
  - browser.type: { selector: "#email", text: "demo@example.com" }
  - browser.click: "button[type=submit]"
  - term.run: "mytool --demo"

Nothing is mocked

The browser panel is the actual site in its own Chrome window, and the terminal streams the output of the commands it really runs. Values flow between them: capture an address from the page, then pass it to a CLI command.

Every format

Landscape, square, feed portrait and vertical, at 1080p or 4K, with layouts for each and areas marked where TikTok, Reels and Shorts cover the picture.

Narration

Voice-over from Kokoro or VibeVoice, or any program you have, paced so each line finishes before the video moves on. Subtitles come with it.

Edit, don't re-record

A timeline editor trims, speeds up and adds text to a take. Sources export each window alone, for your own edit.

Private by default

Redact secrets wherever they appear, blur whole elements, and start from a saved signed-in profile, so no password is ever typed on camera.

Checked before it runs

democast check validates a scene without recording it, and a failed step saves a screenshot of that moment.

Try it

npm install
node src/cli.js examples/tailground.yaml
node src/cli.js edit examples/tailground.yaml

You need Linux or macOS, Node 20+, ffmpeg, and Chrome, Chromium or Edge. The reference covers every setting and flag, and the examples show every way to use it, with a screenshot for most.

Overview

Acme Notes keeps your notes in one place. Items are plain text, and every change saves at once. Nothing leaves your machine unless you share it.

Install

One command installs the command line tool:

npm install acme-notes

Then run acme init in any folder to start a notebook.

Usage

Add a note with acme add "text", list them with acme ls, and remove one with acme rm 3.

Sync

Sync is end-to-end encrypted. Pair a second machine with acme pair and enter the code it prints.

FAQ

  • Is it free? Yes.
  • Does it need an account? No.
  • Where are notes stored? In ~/.acme.
